### 🌟 Project Spotlight: EventFlow

**EventFlow** is my flagship backend system designed to handle high-traffic event registrations and instantaneous physical check-ins without bottlenecks:

- 🛡️ **Role-Based Access Control (RBAC):** Multi-tenant organization hierarchies (superadmins, event organizers, attendees).
- 🎫 **Digital Ticketing &amp; Dynamic QR Check-in:** Cryptographically verified single-use check-in tokens with low-latency barcode scanner validation.
- ⚡ **High Concurrency &amp; Caching:** Redis cache layers for active event metadata and fast ticket token lookups, alleviating database load.
- 📦 **Containerized &amp; Cloud Ready:** Dockerized microservices deployed with automated GitHub Actions CI/CD workflows.
- 🔒 **Security Hardened:** Rate limiting, input sanitization, JWT authentication, and structured error handling.
